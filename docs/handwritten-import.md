# 手書き予約表の取り込み（貼り付け）

電話や店頭で受けた予約を紙の予約表に書き、その文字を管理画面に貼り付けて登録する。
**費用はかからない**（有料の AI・サービスは使わない。文字の読み取りはこのアプリの中だけで行う）。

---

## 全体の流れ（オーナー様の操作）

```
① 予約表を撮影する
② Google フォトで写真を開き、「レンズ」から文字を選んでコピーする
③ 管理画面「手書き予約表の取り込み」で「貼り付け」を押す
④ 「読み込む」を押す
   ↓ 予約の候補の一覧が出る（まだ登録されない）
⑤ 紙と見比べて直す。✖ で取り消した予約は「この行を消す」
⑥ 「登録する」
```

- 文字の作り方は 2 通りどちらでも読める。
  - Google レンズの「テキストをコピー」（文字そのまま。並びが乱れることがある）
  - Google の AI に「予約内容を書き出して」と頼んだ回答（読み違いがあるので必ず紙と見比べる）
- 手で打った文字（`10:00 山田 C2`）でもよい。
- 紙の ✖（取り消し）は文字に出ないことがある。確認画面で人が消す。

---

## 読み取りのルール（`src/lib/paste-import/parse.ts`）

1 行ずつ、次を探す。全角・半角の違いはそろえてから読む。

| 項目 | 読める書き方 |
| --- | --- |
| 時刻 | `10:00` `10：00` `10時` `10時半` `14時30分` `1000`（数字だけは、ほかに時刻が無い行で 7〜21 時・5 分単位のときだけ） |
| 時間の範囲 | `10:00〜10:45` `10:00-10:45` `10時から11時` |
| 日付 | `10/15` `10月15日` `2026年10月15日`。その行から下に効く。無ければ画面で選んだ「この予約表の日付」 |
| 年 | 書いていなければ今年。ただし今年だと 2 か月以上前になるなら来年 |
| 電話番号 | `090-1234-5678` `09012345678` |
| メニュー | 予約表の記号（`C2` `C2+S` `K1+H+E`）・メニューの正式名・略し方の表（`aliases.ts`） |
| お名前 | 残った文字。「様」「さん」は外す |

- 1 件の情報は何行に分かれていてもよい（お名前・メニュー・時刻がそろうまでを 1 件）。
  時刻のある予約にまた時刻が来たら次の予約。お名前も同じ。日付が変わっても次の予約。
- 時刻だけの行は、印刷された時刻の目盛りとして読み飛ばす（予約の時刻にしない）。
- 予約表に印刷された説明（「営業 火〜金 9:30-19:30」など）と AI の前置きの文章は読み飛ばす。
- 何も読めない行は、確認画面のいちばん下に「読み取れなかった行」として出す。
- 似ている書き方（`カツト`→カット、`Cl`→C1、`キングコーズ`→キングコース）は候補にして「要確認」。

### 予約表をそのままコピーした文字（Google レンズ）の限界

2026-10-13 にオーナー様の Pixel で実物を試して分かったこと。

- 予約表は「何曜日の予約か」「何時からか」を**枠の位置**で表している。
  レンズで文字にすると位置が消えるので、**文字だけでは曜日も時刻も分からない**。
- 印刷された時刻の目盛り（9:00・9:30…）と列の見出しの日付は文字に混ざって出てくる。
  これを予約の日時として使うと、もっともらしいが間違った予約になる。
- そのため、次のどちらかに当たる文字は「予約表そのままの文字」とみなす（`sheetMode`）。
  - 印刷された言葉（「この週の火曜日」「取り込み日」など）が 2 つ以上ある
  - 時刻だけの行が 3 行以上ある
- 「予約表そのままの文字」では:
  - 文字の中の日付は使わない。全部の行を「この予約表の日付」にして、「何曜日か分かりません」の要確認を付ける
  - ひとつだけ書かれた時刻は使わない（`9:30〜10:15` のような範囲と `時間：10:00` は人が書いたものとして使う）
  - お名前だけ読めた行も候補として出す（時刻とメニューは確認画面で選ぶ）
- どの文字でも、**時刻だけの行**（`10:00` だけ）は予約の時刻にしない。
- レンズが「翻訳」になっていると、`C2` が「チェコ共和国」、`P1` が「円周率」のように化ける。
  翻訳を切ってから「すべて選択」→「コピー」。

### メニューの略し方を足す

`src/lib/paste-import/aliases.ts` に 1 行足す。

```ts
{ word: "カット", slug: "cut-adult", sure: false },
```

- `slug` は menus テーブルの slug。
- `sure: true` なら判定は OK、`false` なら「要確認」。

### 終了時刻

`src/lib/paste-import/draft.ts` の `END_TIME_POLICY`。

| 値 | 終了時刻 |
| --- | --- |
| `"written-first"`（今の設定） | 紙に終了時刻が書いてあればそれ、無ければメニューの所要時間 |
| `"menu"` | いつもメニューの所要時間 |

確認画面でも行ごとに「メニューの時間にする」「紙の時刻にする」で切り替えられる。

## 確認画面の判定（`src/lib/paste-import/judge.ts`）

直すたびにその場で判定し直す。「登録する」を押したときも、サーバーで最新の予約を読んでもう一度判定する。

| 判定 | こんなとき | チェック |
| --- | --- | --- |
| OK | 問題なし | 最初から付いている |
| 要確認 | メニューを似ている名前で選んだ／読めない記号があった／営業時間の外／お休みの日 | 最初は外れている（自分で付けられる） |
| エラー | 時刻・お名前・メニューが無い／過去の日時／すでにある予約と重なる／一覧の中で重なる／同じ予約が登録済み | 付けられない |

- 「同じ予約」= 同じ日・同じ開始時刻・同じお名前（姓だけでも同じとみなす）。
  同じ文字を 2 回貼り付けても、2 回目は全部エラーになり二重登録されない。
- 営業時間・お休みの判定は、ネット予約と同じ `src/lib/calendar.ts`（臨時休業の設定も含む）。

---

## 登録

- チェックした行だけを、データベースの関数 `import_handwritten_reservations` で**まとめて**登録する。
  1 件でも登録できなければ、全部取り消す（途中まで登録された状態にならない）。
- 登録した予約: **確定・店頭払い・未払い**、登録経路 `handwritten`（管理画面では「手書き」）。
  Stripe の支払いは無し。**メールは送らない**（メールアドレスが空なので、前日のお知らせメールも送られない）。
- ネット予約の空き枠からは、ほかの予約と同じく外れる。
- 時間の重なりは、最後はデータベースの制約（`no_overlap_active`）でも防いでいる。

データベースの準備: `supabase/migrations/20261012000001_paste_import.sql` を Supabase の SQL Editor で 1 回実行する
（登録経路に `handwritten` を足し、登録用の関数を作る。既存の予約は変えない）。

## 予約表（紙）

印刷用 PDF: 管理画面の取り込みページ上部「予約表（印刷用 PDF）」
（実体は `public/booking-sheet.pdf`。`python scripts/make_booking_sheet.py` で作り直せる）

- **2 ページ**。
  | ページ | 向き | 内容 |
  | --- | --- | --- |
  | 1 | A4 横 | 予約表 … 火〜日の 6 日分（A〜F 列）。1 週間で 1 枚 |
  | 2 | A4 縦 | メニュー早見表（料金・所要時間）・書き方・記入例・お客様メモ |
- 曜日は火〜日を印刷済み（月曜は定休なので無い）。日付欄には月・日だけを書く。
- 1 行 = 15 分、9:00〜19:30。横線は**すべて破線**で印刷してある。
- 予約が入ったら、その時間帯の上下の破線を**なぞって実線**にし、四角で囲む。
- 1 日分の中は「名前」「コース」の 2 欄。**四角の中に書く**（行をまたいでよい）。
- **取り消すときは、名前・コースの上から ✖ をかぶせる**。
- 取り込んだら、予約表の「取り込み日」に日付を書く。

### ✖ を文字ではなく線で描いている理由

✖ の文字は PDF の日本語フォントに入っておらず、文字で書くと印刷時に消える。
予約表の生成スクリプトでは、✖ を 2 本の線で描いている（`draw_cross`）。

### メニュー記号の書き方

コース記号をまず書き、オプションを付ける場合だけ「+記号」を続ける。

| 書き方 | 意味 |
| --- | --- |
| `C2` | カット・シャンプー のみ |
| `C2+S` | カット・シャンプー ＋ お顔剃り |
| `K1+H+E` | カラー ＋ 頭皮スパ ＋ 耳洗い |

オプションの記号（2026-09 改定）

| 記号 | メニュー | 記号 | メニュー |
| --- | --- | --- | --- |
| `+S` | お顔剃り | `+E` | 耳洗い |
| `+H` | 頭皮スパ | `+N` | 鼻脱毛 |
| `+FS` | フェイススパ | `+M` | 眉毛剃 |
| `+FP` | フェイスパック | `+L` | デザインライン |
| `+K` | 角質落とし | `+SF` | スキンフェード |

- 小文字・全角（`ｃ２＋ｓ`）でも読める。「+」を書き忘れても `C2S` → `C2` と `+S` に分ける。
- `SF` と `S` のように前が重なる記号は、長いほうを優先する。
- 旧記号（`+剃` `+頭` など）も読める。

### メニュー記号の変更

`src/lib/sheet/menu-codes.json` を直し、予約表 PDF を作り直す。
取り込み側も同じ JSON を読むので、コードの変更は不要。
