# オーナー様への LINE 連絡テンプレ（Web予約アプリの共有）

デプロイして URL が確定してから送る。`<URL>` は実際のものに差し替えること。

---

## ① 予約アプリを見てもらう（1通目）

```
お疲れさまです！
予約専用のページができたので、共有します。

こちらから見ていただけます。

URL: <URL>
ID:  STONES
パスワード: 2018

開くとID とパスワードを聞かれるので、上の2つを入力してください。
（一度入れると、しばらくは聞かれなくなります）

お客様には、この画面から予約してもらう形になります。
お試しで予約を入れていただいても大丈夫です。
こちらで消しておきます。
```

## ② 管理画面の案内（2通目）

```
【お店側の画面について】

予約の確認や変更は、こちらからできます。

URL: <URL>/admin
メールアドレス: inotokoya1119@yahoo.co.jp
パスワード: Shinichirou1119@

こちらは先ほどのID・パスワードは不要です。
上のメールアドレスとパスワードだけで入れます。

■ できること
・入っている予約の確認（一覧・カレンダー）
・お電話でいただいた予約の登録
・予約の日時変更・キャンセル
・臨時休業日の設定（設定するとお客様の画面にも反映されます）
・メニューや料金の変更

予約が入ると inotokoya@yahoo.co.jp にお知らせメールが届きます。
オーナーさんの操作は不要で、見るだけで大丈夫です。
```

## ③ 触ってもらうときのお願い（必要なら）

```
もしよければ、次の2つだけ試していただけると助かります。

1. お客様のつもりで、予約を1件入れてみる
2. 管理画面で、その予約が入っているか見てみる

「ここが分かりにくい」「この言葉が伝わりにくい」など、
気づいたことがあれば何でも教えてください。直します。

うまく動かないところがあれば、その画面のスクショを
送っていただけると助かります。
```

## 補足（自分用メモ）

- 今はまだ ID / パスワード付き。本公開（誰でも予約できる状態）にするには
  Vercel の環境変数 `SITE_PASSWORD` を空にして再デプロイする。
  → **オーナー様の了承を取ってから**行うこと。
- 紹介サイト（stonesbarber.com）の「予約はこちら」ボタンのリンク先を
  新 URL に差し替えるかどうかも、あわせて相談する。
  Jimdo はオーナー様の資産なので、勝手に触らない。
- 既存の `stones-barber.vercel.app` も生きているが、オーナー様には
  新 URL だけを案内する（2つ伝えると混乱するため）。
